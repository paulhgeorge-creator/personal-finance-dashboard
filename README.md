# Investment Risk Dashboard



Comparing savings, bonds, index funds, and crypto is hard when each is explained in a different way. This dashboard puts the risk, volatility, and projected return of all four asset classes side by side so a beginner can see the trade-offs at a glance.

## Features

- Overview page with a risk badge, average return, and volatility for each asset class
- A detail page per asset class (savings, bonds, index funds, crypto) with risk profile cards and interactive sliders
- Light and dark theme toggle

## Tech stack

Next.js (App Router) · React · TypeScript · Tailwind CSS · shadcn/ui

## How to run

```bash
git clone https://github.com/paulhgeorge-creator/personal-finance-dashboard.git
cd personal-finance-dashboard
npm install
npm run dev
```

Open http://localhost:3000. Run `npm run lint` to check the code.

## Disclaimer

For educational purposes only. Not financial advice. Return and volatility figures are illustrative assumptions in `lib/financial-data.ts`.
